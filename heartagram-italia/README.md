## Pubblicazione in una repository autonoma

1. Crea una repository **pubblica** chiamata "heartagram-italia" nell'account "salvatoresinatra0001-ux".
2. Copia i **contenuti di questa directory nella radice** della nuova repository (non la cartella "heartagram-italia" come sottocartella): "index.html", "README.md" e ".github/workflows/deploy-pages.yml".
3. Imposta **Settings → Pages → Build and deployment → GitHub Actions**.
4. Esegui il workflow "Pubblica Heartagram Italia", se non si avvia automaticamente.
5. Verifica l'URL: https://salvatoresinatra0001-ux.github.io/heartagram-italia/

La creazione della repository separata e il primo deployment sono operazioni distinte dall'aggiunta al portale Music Archives Italia: **non sono ancora avvenute automaticamente**.

## Manutenzione
