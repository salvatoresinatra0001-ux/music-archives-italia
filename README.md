## 2. Edizioni indipendenti

I progetti con repository autonome restano separati: [Heartagram](https://github.com/salvatoresinatra0001-ux/heartagram-italia), [Mylène Farmer](https://github.com/salvatoresinatra0001-ux/mylenefarmer-italia), [Sandra](https://github.com/salvatoresinatra0001-ux/sandra-italia), [Mesh](https://github.com/salvatoresinatra0001-ux/mesh-italia), [Assemblage 23](https://github.com/salvatoresinatra0001-ux/assemblage23-italia), [The Birthday Massacre](https://github.com/salvatoresinatra0001-ux/the-birthday-massacre-italia) e [Rammstein](https://github.com/salvatoresinatra0001-ux/rammstein-italia).

Sono versioni editoriali **complementari**, non file intercambiabili o da sovrascrivere. I siti Mesh e Assemblage 23 dispongono di una directory di pubblicazione `site/`. La versione centrale pubblica invece le sottocartelle della repository master.

## 3. Assemblaggio e preservazione

Il workflow estrae l'archivio storico v13.1 e **sovrappone** le directory modificabili della repository, incluse le quattro espansioni v20 e l'Atlante. Genera inoltre il catalogo strutturato storico e la sitemap. Lo ZIP originario e tutte le schede esistenti rimangono preservati.

I riferimenti fotografici non equivalgono a file con diritti di riuso autorizzati. Le immagini presenti nei siti indipendenti non sono automaticamente copiate nella raccolta principale. Le discografie sono selezioni editoriali e richiedono verifica delle fonti prima di essere definite complete.

## 4. Verifiche di pubblicazione

La presenza dei file nella repository **non certifica** GitHub Pages operativo: controllare Actions, Pages, navigazione, collegamenti, accessibilità e gli URL pubblici dopo il merge. Vedere anche [standard editoriale](EDITORIAL-STANDARD.md) e [archivio strutturato](STRUCTURED-ARCHIVE.md).
